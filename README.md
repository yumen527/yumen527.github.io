# 我的感悟笔记

入口文件是 `index.html`，双击即可打开。

## 使用方式

- 首页是一组书架，每个书架对应一个文件夹。
- 进入文件夹后，可以继续添加子文件夹，也可以添加笔记。
- 点击笔记进入阅读页，点“编辑”可以修改内容。
- 新增和编辑的数据会保存在当前浏览器的 `localStorage`。

## 初始笔记

`notes-data.js` 会作为第一次打开网站时的初始数据来源。原来的 Markdown 已放在：

```text
notes/思考随笔/第一篇.md
```

## 文件

- `index.html`：网站入口
- `styles.css`：书架界面样式
- `app.js`：新增、编辑、路由和本地保存逻辑
- `notes-data.js`：初始笔记数据
- `notes/`：原始 Markdown 笔记
- `build-notes.ps1`：重新生成初始数据的脚本
